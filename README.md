# Tic-Tac-Toe-Squared
It is the ultimate final boss of Tic Tac Toe rip-offs

# How to install
1. Install the index.html file in the guthub repo
2. Open it and you can start playing

# How to open game code
1. Install the index.html file
2. Open it in any code editor like VS Code, Notepad, etc

# How to play
This is a complicated game. You need 2 people to play this. One person can play as X and the other one as Y. So basically there are 9 smaller tic tac toe boards inside a big tic tac toe board. Player 1 can decide to play whwerever they want. For example lets say player 1 chooses the top right board to start, and they decideto put X in the center of that board, PLayer 2 can only use the center board and this continues. If any of the board is full or captured, the player whose turn it is can choose whichever board they want. First one to capture 3 board in a row wins the entire game.
